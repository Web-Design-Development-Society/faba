# ADR-010: Basic RSVP and minimal moderation move into Phase 1

- **Status:** Accepted
- **Date:** 2026-10-28, accepted 2026-10-29
- **Decided by:** proposed in the FABA design document; accepted by Zack Alvey (FND-02, open question 11)
- **Related:** design document section 5.1

## Context

The suggested outline put RSVP in Phase 2 and moderation in Phase 3. Without RSVP, Phase 1 is a bulletin board, and organizers can't see who's coming. Members post content from day one, so the board needs a way to respond from day one.

## Decision

Phase 1 includes:

- A basic "I'm going" RSVP, the going count, and the attendee list.
- Edit and cancel for activities.
- Minimal moderation: report, hide, suspend, and an audit log.

Capacity, "maybe", guests and waitlists stay in Phases 2 and 3. Notifications about changes stay in Phase 2. Richer moderation tools stay in Phase 3.

## Consequences

- Phase 1 is bigger than the outline, while the target is to launch during Fall 2026. Cut elsewhere before cutting these.
