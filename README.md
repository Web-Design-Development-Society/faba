# FABA

**Faculty Association BYUI Activities** helps BYU-Idaho faculty find and organize activities around Rexburg. Members can post events, RSVP, join groups and leagues, and keep up with updates. FABA is an independent, mobile-first community for faculty with a `byui.edu` Google account; it is not an official university channel.

## Develop

FABA runs on [Astro](https://astro.build) and Cloudflare Workers, with Supabase for authentication and data. To set up the local app and database, see [Contributing](./CONTRIBUTING.md).
